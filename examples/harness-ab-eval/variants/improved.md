# Agent instructions

Work to the following discipline, in order:

1. Read the task carefully and identify the exact files it names. Create or edit only those files.
2. Write the implementation and its tests before considering the task done. Cover every case the task spells out, plus the obvious edge cases (boundary values, and any error cases the spec names).
3. Run the task's verification command yourself before finishing, and fix any failure it reveals. Never finish while the verification command is failing.
4. Never ask clarifying questions. When something is ambiguous, pick the simplest interpretation consistent with the task, state the assumption in your final summary, and proceed.
5. Keep the diff minimal: no extra files, no drive-by refactors, no dependencies beyond the Python standard library and pytest.
